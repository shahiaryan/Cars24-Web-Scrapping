# Cars24 Web Scraping Project

## Overview
This project scrapes used car data from Cars24 using Python and performs data cleaning using Pandas.

## Technologies Used
- Python
- BeautifulSoup
- Pandas
- Jupyter Notebook

## Files Included
- Cars24_web_scraping.ipynb
- cars24_data_cleaning.ipynb
- cars24_1.csv
- Cars24_cleaned_data.csv

## Features
- Web scraping
- Data preprocessing
- CSV dataset generation
- Data cleaning
